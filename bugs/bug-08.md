# BUG-08: POST /api/books руу JSON биш бие илгээхэд API ном хадгалаагүй атлаа 200 OK, {"result":"OK"} гэж амжилттай гэж хариулна

Орчин: Уншлагын жагсаалт v2.0, curl 8.7.1, macOS 15.6, 2026-10-16

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминалд дараах командыг ажиллуулна:
   `curl -i -X POST http://localhost:3000/api/books -H 'Content-Type: application/json' -d 'буруу оролт'`
2. Хариуны статусын мөр болон биеийг харна.
3. `curl -i http://localhost:3000/api/books` командыг ажиллуулж номын жагсаалтыг харна.

Хүлээгдэж байсан: Спецификаци — «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана». `400 Bad Request` болон алдааны тайлбар буцаах ёстой.

Бодит үр дүн: `HTTP/1.1 200 OK`, `{"result":"OK"}`. Гэвч 3-р алхамд жагсаалтад 3 ном хэвээр — юу ч хадгалагдаагүй. API алдааг нууж, амжилттай гэж худал хариулж байна.

Ноцтой байдал: Major — API-г ашиглаж буй клиент өгөгдөл хадгалагдсан гэж үзэх тул өгөгдөл чимээгүй алдагдана. Алдааг илрүүлэх боломжгүй.
