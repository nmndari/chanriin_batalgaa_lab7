# BUG-09: DELETE /api/books/{id} нь байхгүй id-тай номыг устгахад 404 биш 200 OK, {"result":"OK"} буцаана

Орчин: Уншлагын жагсаалт v2.0, curl 8.7.1, macOS 15.6, 2026-10-16

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном, id = 1, 2, 3)

## Дахин гаргах алхам

1. Терминалд дараах командыг ажиллуулна:
   `curl -i -X DELETE http://localhost:3000/api/books/999`
2. Хариуны статусын мөр болон биеийг харна.
3. `curl -i http://localhost:3000/api/books` командыг ажиллуулж номын жагсаалтыг харна.

Хүлээгдэж байсан: Эрүүл ухаан (REST API-ийн ердийн дүрэм) — байхгүй нөөцийг устгах хүсэлтэд `404 Not Found` болон алдааны тайлбар буцаана. (Апп өөрөө бусад тохиолдолд `{"result":"ERROR_NOT_FOUND"}`, 404 буцаадаг.)

Бодит үр дүн: `HTTP/1.1 200 OK`, `{"result":"OK"}`. 3-р алхамд 3 ном хэвээр — юу ч устаагүй атлаа амжилттай гэж хариулна.

Ноцтой байдал: Minor — өгөгдөл гэмтэхгүй ч клиент буруу id илгээснээ (жишээ нь өөр хэрэглэгч аль хэдийн устгасан) мэдэх боломжгүй.
